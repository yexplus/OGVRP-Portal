# ogvrp portal

little app i made for ogvrp staff to review civilian apps way faster. (not being used, sadly)

### features

* **brand new UI:** everything is now inside one window - Review, History, Hotkeys, Customize and Discord, no more pop-up windows.
* **quick discord responses:** generates accept and deny messages pre-formatted so you can just copy-paste them right into discord.
* **easy reason cards:** click to mark common issues like bad scenario answers, rule breaks, ai-written apps, underage accounts, etc. with tabs (All / Rules / Scenes / Admin / My Reasons) plus search.
* **real discord login:** connect your real discord account - your name and avatar show in the app (login only, the app never sends messages for you).
* **discord preview that looks like discord:** dark bubble, your real avatar, mention and channel pills, bold and italic rendered properly.
* **custom themes & backgrounds:** pick any accent colour you want, a colour or image background with 4 built-in wallpapers (Ocean, Sunset, Forest, Midnight), frosted-glass panels with an opacity slider.
* **dark & light theme:** works with both dark and light modes, fitted to windows 11 style.
* **history:** shows the failure reasons under each entry, with search, pass/fail counts and Export CSV. history is archived every month instead of deleted.
* **auto-updater:** automatically checks github for new versions on startup and updates itself.
* **portable:** just one `.exe` file. no installer, no setup.
* and more!

### how to use

**windows:**
1. go to **releases** on the right side of this page.
2. download `OGVRP Portal.exe`.
3. open it and start using it.

**mac:**
1. go to **releases** on the right side of this page.
2. download the zip for your mac:
   * `OGVRP-Portal-macOS-arm64.zip` - Apple Silicon macs (M1 / M2 / M3 / M4)
   * `OGVRP-Portal-macOS-x64.zip` - older Intel macs
3. double-click the zip to unzip it, then drag `OGVRP Portal.app` into your Applications folder.
4. the first time you open it, right-click the app -> Open -> Open. macOS blocks it on a normal double-click because the app isn't notarized, but after that it opens normally.
