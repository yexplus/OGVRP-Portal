# ogvrp portal

little app i made for ogvrp staff to review civilian apps way faster.

### features

* **quick discord responses:** generates accept and deny messages pre-formatted so you can just copy-paste them right into discord.
* **easy checkboxes:** click to mark common issues like bad scenario answers, rule breaks, ai-written apps, underage accounts, etc.
* **dark & light theme:** works with both dark and light modes, fitted to windows 11 style.
* **auto-updater:** automatically checks github for new versions on startup and updates itself.
* **portable:** just one `.exe` file. no installer, no setup.

### how to use

1. go to **releases** on the right side of this page.
2. download `OGVRP Portal.exe`.
3. open it and start using it.
